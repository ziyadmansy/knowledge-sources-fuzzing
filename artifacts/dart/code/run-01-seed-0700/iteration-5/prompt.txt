What is already known about these four implementations, from reading

2. json_serializable and freezed share JSON decoding logic via `$enumDecode`, throwing `CheckedFromJsonException` on unknown enum strings. 5. Manual and built_value require `id` strictly as int; json_serializable and freezed accept any num and convert via `.toInt()`.

6. Manual and built_value throw raw or wrapped `ArgumentError` on unknown enum strings; json_serializable and freezed throw documented `CheckedFromJsonException`.
